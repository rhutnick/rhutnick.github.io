## Add the Identity Verification PowerPoint
Put the deck in `assets/docs/`, then update `case-identity.html` to link to it. This keeps the artifact separate from the page content.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Repository → Settings → Pages.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and use the URL GitHub provides.

## Practice page
`practice.html` is separate from the public navigation. Plain GitHub Pages is not password protection; anyone who knows the URL can access it. Use an authenticated hosting layer if you want true privacy.
